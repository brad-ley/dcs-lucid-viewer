Analog Control¶

Analog Control contains features that describe how to influence the analog features of an image, such as gain, black level, and gamma. Features related to white balance are not available on monochrome cameras.

Node Name Description
GainSelector Selects which Gain is controlled by the various Gain features.
Gain Controls the selected Gain as an absolute physical value.
GainRaw Reports the gain raw value.
GainAuto Sets the automatic gain control mode.
GainAutoLowerLimit Specifies the lower limit of GainAuto algorithm.
GainAutoUpperLimit Specifies the upper limit of GainAuto algorithm.
BlackLevelSelector Selects which BlackLevel is controlled by the various Black Level features.
BlackLevel Controls the BlackLevel as an absolute physical value.
BlackLevelRaw Controls the raw BlackLevel value.
BalanceRatioSelector Selects which BalanceRatio is controlled by the various Balance Ratio features.
BalanceRatio Controls the selected BalanceRatio as an absolute physical value. This is an amplification factor applied to the video signal.
BalanceWhiteAuto Controls the mode for automatic white balancing between the color channels. The white balancing ratios are automatically adjusted.
BalanceWhiteEnable Actives balance white features.
BalanceWhiteAutoAnchorSelector Controls which type of statistics are used for BalanceWhiteAuto.
AwbDamping Controls the auto white balance damping factor in percent.
AwbDampingRaw Controls the auto white balance damping factor raw value.
AwbWhitePatchEnable Controls if the white patch algorithm is used for BalanceWhiteAuto.
AwbStatsFrameCount Controls how many frames are used for collecting statistics for BalanceWhiteAuto.
AwbAOI Category for auto white balance AOI features.
GammaEnable Controls the selected balance ratio as an absolute physical value. This is an amplification factor applied to the video signal.
Gamma Controls the gamma correction of pixel intensity.
SharpeningEnable Controls if the sharpening feature is enabled.
SharpeningAmount Controls the sharpening amount.
SharpeningThreshold Controls the minimal brightness change that will be sharpened.The threshold setting can be used to sharpen more pronounced edges, while leaving subtler edges untouched.
DualADCMode Configures whether to enable the Dual ADC feature and what mode to enable it in.
DualADCGain Displays the resulting total gain of the second imager ADC.
DualADCGainOffset Displays the extra gain to be added to the second ADC.
DualADCGainOffsetRaw The raw register value of the DualADCGainOffset.
DualADCAnalogGainMax Controls the maximum analog gain to use for the primary ADC. Extra gain will be digital.
DualADCAnalogGainMaxRaw The raw register value of the DualADCAnalogGainMax.
DualADCSelectionThreshold Configures the percentage of the pixel intensity to use for the cutoff between both ADC outputs.
GradationCompressionMode Configures whether to enable the gradation compression feature and what mode to enable it in.
GradationPointCount Configures the number of gradation knee points to use for the gradation compression feature.
GradationPointSelector Selects the gradation knee point to modify for the gradation compression feature.
GradationIntensityStart The pixel intensity above which the gradation compression settings will be applied for this point.
GradationIntensityStartRaw The raw register value of the GradationIntensityStart.
GradationGain The gain used to scale all pixel intensities above the GradationIntensityStart threshold.
GradationGainRaw The raw register value of the GradationGain.
