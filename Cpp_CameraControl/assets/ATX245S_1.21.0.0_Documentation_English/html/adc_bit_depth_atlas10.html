ADC bit mode¶

The three ADC bit modes available in ATX245S are 8 Bit, 10 Bit and 12 Bit. As a result of sensor being clocked differently for each of these bit modes, the maximum frame rate achieved is different in each mode.

The following table shows the maximum frame rate achieved using the Mono8 pixel format.

Atlas model 8 Bit (FPS) 10 Bit (FPS) 12 Bit (FPS)
ATX245S 50.6 50.6 46.6
ATX204S 61.0 61.0 56.8
ATX162S 75.6 76.1 68.9
