Configuring an Output Line¶

When a Digital IO line is set to Output, the line can fire pulses.

The following pseudocode demonstrates how to set Line1 as the output source. This sets up the camera to fire a pulse when the camera is acquiring an image.

// Connect to camera
// Get device node map 

// Choose Line1 and set it to Output 
LineSelector = Line1;
LineMode = Output;
LineSource = ExposureActive;            // The output pulse will match the duration of ExposureTime

AcquisitionStart();

// Acquire images and process signal from Line1
Opto-isolated outputs will require external circuitry to be properly signaled. Some Digital IO lines may be Output only (e.g., an opto-isolated output). Consult the GPIO Characteristics section for a GPIO pinout diagram.
