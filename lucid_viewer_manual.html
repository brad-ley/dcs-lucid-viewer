lucid_viewer.py¶

A PyQt6 desktop viewer for LucidLabs ATX245 mono-camera acquisitions. Opens raw camera files, applies dark-field / white-field corrections (flat field or PCA-based background removal), and exports corrected stacks as TIFF or GIF.

Supported file formats¶

ExtensionHow it is read
.rawBinary blob; frame geometry and pixel format read from JSON sidecar or entered manually
.tiff / .tifMulti-frame TIFF via tifffile
.mp4 / .aviVideo via opencv-python

JSON sidecar¶

When opening a .raw file the viewer searches for metadata in this order:

  1. <file>.json (e.g. capture_Mono12p.raw.json)
  2. <stem>.json (e.g. capture_Mono12p.json)
  3. metadata.json in the same folder

Keys read: width, height, pixel_format (also pixelformat / PixelFormat for legacy sidecars), fps, acquisition_time, notes, field_references.

If no sidecar is found the viewer infers the pixel format from the filename (e.g. a file containing Mono12p is parsed as Mono12p). Width/height default to the ATX245 full sensor (5328 × 4608).

Opening a file¶

File → Open file… (Ctrl+O) or click Open image file… in the sidebar.

The Frame format group lets you set pixel format, width, and height before or after opening. After changing any of these, click Re-parse to re-read the current file with the new parameters without opening a dialog.

Frame navigation¶

  • Frame slider — scrub through frames; a tick marks the trigger frame.
  • ← / → — step one frame backward / forward.
  • Home / End — jump to the first / last frame.
  • Space or ▶ Play button — start/stop real-time playback at the file’s native FPS.

Display controls¶

Colormap — choose any pyqtgraph or matplotlib colormap from the sidebar drop-down.

Auto levels — sets the display range to the 3rd–97th percentile of the current frame. Applied automatically when a new file is opened.

Pixel mask — overlays colour indicators on the image:

  • Red — saturated pixels (at or above the bit-depth maximum)
  • Yellow — dead pixels (value = 0)

Field correction¶

Corrections are controlled in the Correction panel in the sidebar. When correction is active the display shows 32-bit float x-ray transmission (values ≈ 0–1); raw sensor counts are shown otherwise.

Dark field¶

Check Dark field to subtract a dark reference.

Auto-detection: on file open the viewer scans for a folder whose name contains dark_field among the siblings of the data folder and one level up. Multiple candidates are sorted by folder-name timestamp proximity. Only folders whose frames match the current width × height are accepted.

When the dark reference was captured at a different gain, it is scaled:

dark_scaled = dark × 10^((data_gain − dark_gain) / 20)

Flat white field¶

Choose Flat field in the white-field combo and check White field.

# dark + white
transmission = (data − dark) / (white − dark)

# white only
transmission = data / white

# dark only
corrected = data − dark

Auto-detection: same timestamp-proximity logic as dark field, searching for folders whose names contain white_field.

PCA background removal¶

Choose PCA removal in the white-field combo and check White field.

PCA builds an eigenvector basis from multiple white-field frames. For each data frame it estimates the beam background via projection and divides:

bg    = mean + V.T @ (V @ (data − mean))
trans = clip(data / max(bg, 0.5 × mean), 0, 10)

where V is the (n_components, H×W) matrix of eigenvectors from SVD of the white-field frames. The basis is computed in a background thread the first time it is needed; progress is shown in the correction status label.

N components spin box — number of PCA modes to subtract (1–20, default 5). More components capture more beam variation but risk subtracting sample signal.

Click PCA settings… (also reachable via Config → Set White Field → PCA…) to open the full PCA configuration dialog.

Gaussian blur dual-resolution PCA¶

Enable Gaussian blur for temporal weight projection in the PCA Settings dialog.

Motivation: projecting a data frame directly onto the white-field basis can pick up sample-structure signal as spurious beam coefficients. Blurring the frame first suppresses high-frequency sample detail, so the projected coefficients reflect smooth beam variation only.

d_low  = blur_and_bin(data, σ) − mean_low   # FFT blur + block downsample
coeffs = V_low @ d_low                          # project in low-res space
bg     = mean + V_high.T @ coeffs              # reconstruct at full resolution

V_low and V_high are eigenvector matrices computed on blurred and full-resolution white frames respectively; they correspond row-by-row to the same mode index. The Gaussian blur is FFT-accelerated (O(H⋅W⋅log(H⋅W))); the kernel is built once in frequency space and cached. Downsampling factor B = min(16, max(1, ⌊σ / 50⌋)).

Blur sigma (default 400 px) should be much larger than the features you want to suppress. 200–600 px covers typical cell sizes on a 5 Mpx sensor.

Master / Universal PCA¶

Enable Universal mode (master no-cell basis) in the PCA Settings dialog.

Why: the x-ray cell changes between experiments, shifting the mean white-field image. Universal PCA avoids a full SVD recomputation for every cell: a single master basis is computed once from a cell-free capture and then adapted per-experiment.

Adaptation math:

T_cell    = W_cell / W_master            # per-pixel gain map
E_cell[i] = T_cell × E_master[i]        # scale each eigenvector
E_cell[i] /= |E_cell[i]|                # row-normalize

When Gaussian blur is also active, the low-resolution components are adapted identically: Q_cell[i] = (T_cell_low × Q_master[i]) / |…|.

Setting the master folder — Config → Set White Field → Master PCA…

The viewer also auto-detects the master folder when Universal mode is first activated: it walks up to 4 directory levels searching for a sibling folder whose name contains _master. Timestamp-proximity sorting picks the closest match. The auto-detected path is saved to settings and shown in the status label.

Cell white field in Universal mode: the viewer prefers a white_field folder that does not contain _master in its name. Falls back to any matching folder if none is found.

Tooltip: after successful cell adaptation, hovering the ✓ White info label shows both the master folder path and the cell white-field folder path.

Storing field references¶

Once the desired correction is active, click Store in the Correction panel. The current folder paths are written into the file’s sidecar JSON under field_references. On the next open of the same file the same correction is applied automatically — no manual setup needed.

Keys written: dark_folder, white_folder, white_pca_folder, white_pca_master_folder, pca_universal, white_mode.

Export¶

TIFF stack export¶

File → Export TIFF stack… (Ctrl+E). Requires tifffile.

All frames are exported with the active correction applied. Corrected frames are written as float32; uncorrected frames as uint16. The output filename is auto-suggested with a suffix indicating the active correction (_pca, _dark_pca, _dark_white, etc.).

Export settings — Config → Export settings…

  • Compression — None / LZW / ZSTD. ZSTD gives the best ratio for float32 data; LZW is good for uint16. None gives maximum read speed.
  • ImageJ mode — writes an ImageJ-compatible TIFF. Automatically falls back to standard BigTIFF for stacks > 3.9 GB (the ImageJ hard limit). Fiji opens BigTIFF files via Bio-Formats.

A JSON sidecar is written alongside the TIFF containing: source file, pixel format, frame count, FPS, timestamps, gains, exposures, and correction parameters.

Note

Stacks larger than 4 GB are automatically written as BigTIFF regardless of the ImageJ mode setting.

GIF export¶

File → Export GIF… (Ctrl+G). Requires Pillow.

  • Frame step — export every Nth frame (1 = all frames).
  • Scale — resize factor (e.g. 0.25 for quarter resolution).
  • FPS — playback speed of the output GIF.

The current display levels (brightness/contrast window) are applied when rendering each frame, so what you see is what you get in the GIF.

Timestamps and trigger¶

Per-frame timing is read from frame_data.csv (or timestamps.csv) in the same folder. The timestamp column is auto-detected by header keyword (timestamp / time / ts / ticks / device / system) and unit suffix (_ns, _us, _ms, _s).

The viewer reads the line_status_all column (a binary string, e.g. 00000101). The configurable trigger bit (default: bit 2, 3rd bit from the right) marks the first frame where that bit goes high as t = 0. Frames before the trigger have negative timestamps; frames after have positive ones. Without a trigger, times are relative to the first frame.

Config → Trigger settings… — change which bit is used as the trigger.

Directory naming conventions¶

Auto-detection searches folder names for these keywords:

Folder name containsUsed as
dark_fieldDark field reference
white_fieldWhite field reference (flat or PCA)
white_field but not _masterCell white field in Universal PCA mode
_masterMaster (cell-free) white field for Universal PCA

Search order: siblings of the data file’s folder first, then one level up. The closest-by-timestamp match is always preferred.

Example layout:

experiment_root/
  20250501_120000_master_white_field/   ← master (cell-free) white field
  20250501_133000_dark_field/           ← dark field for session
  20250501_133000_white_field/          ← shared white field (flat mode)
  20250501_140000_cell_A/
    capture_Mono12p.raw
    metadata.json
    frame_data.csv
    white_field_20250501_140000/        ← cell A white field (Universal PCA)
  20250501_153000_cell_B/
    capture_Mono12p.raw
    metadata.json
    frame_data.csv
    white_field_20250501_153000/        ← cell B white field (Universal PCA)

With Universal PCA active and cell A open, the viewer finds 20250501_120000_master_white_field as the master folder and white_field_20250501_140000 as the cell white field.

Settings persistence¶

All preferences are saved via QSettings (Windows Registry / platform-native store) and restored on next launch:

  • Last opened file path
  • Pixel format, width, height
  • Colormap
  • PCA blur enabled / blur sigma
  • PCA Universal mode / master folder path
  • Export compression / ImageJ mode
  • Trigger bit
